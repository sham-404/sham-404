## 🧠 About Me

I’m a developer learning my way through multiple languages, low-level systems, and cool algorithms:

- 🔭 **Currently building:** A lot of algorithm visualizers, CLI tools, and local multiplayer games.
- 🌱 **Currently learning:** Diving into **Rust** for CLI tools and exploring **Flutter** for cross-platform apps. 
- ⚙️ **My Environment:** antiX Linux, Zsh, and a custom minimal, IDE-like Neovim setup. 
- 🧩 **Stuff I explore:** Wave Function Collapse, Fourier series, data structures, and terminal environments.
- 🚀 **My goals:** Keep learning, keep building, keep ricing — one bug at a time.
